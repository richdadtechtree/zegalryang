四뮤즈에게 전달할 약속

웹앱(richdadtechtree.com)과 앱이 이 모양만 지키면 상소와 서로 덮어쓰지 않습니다.

  1. 군령 체크: my-wiki 저장소의 어제보다 나은 오늘/군령.md. 맨 위 ## 날짜 아래 두 줄을 체크박스로 보여 주고, 체크하면 그 줄의 [ ]↔[x] 한 글자만 바꿉니다.
  2. 저장 방법: GitHub Contents API로 읽을 때 받은 sha를 함께 보내 저장합니다. 409가 오면 다시 읽고 다시 고쳐 저장합니다.
  3. 할 일 체크(진행 중): 코딩/Claude 대화/YYYY-MM-DD-claude.md의 ## 다음 할 일 아래 - [ ]를 그 자리에서 - [x]로. 칸 제목과 파일 이름의 날짜는 그대로 둡니다.
  4. 오늘 기분 · 1년 뒤 나에게: 어제보다 나은 오늘/ 폴더에 저장. 기분은 ## 날짜 아래에 덧붙이고, 1년 뒤 파일은 이름에 '1년 뒤'를 넣습니다.
  5. 토큰: 깃허브 토큰은 서버 쪽에서만 씁니다. 브라우저 코드에 넣으면 누구나 볼 수 있습니다.

저장소: richdadtechtree/my-wiki (옵시디언 볼트 = 저장소 루트)

1) 군령 장부 — 어제보다 나은 오늘/군령.md
   - 상소 프로그램이 매일 아침 맨 위(머리말 바로 아래)에 새 날짜를 끼워 넣음:
       ## 2026-11-26
       - [ ] 道具 · (클로드 코드로 할 일)
       - [ ] 大業 · (삶·사업에서 할 일)
   - 웹앱·앱은 맨 위 날짜의 두 줄을 체크박스로 보여 줌. (지난 날짜도 보여 주면 좋음)
   - 체크/해제 = 그 줄의 "[ ]" ↔ "[x]" 한 글자만 바꿈.
     줄 내용, 꼬리표(道具·大業), "## YYYY-MM-DD" 제목, 줄 순서는 바꾸지 않음.
   - 저장: GET /repos/richdadtechtree/my-wiki/contents/{경로} 로 content(base64)와 sha 를 받고,
           PUT 같은 주소에 {message, content(base64), sha} 로 저장.
           409 가 오면 다시 GET → 다시 고침 → 다시 PUT (최대 3~4번).
   - 다음 날 상소는 [ ] 는 '못 한 일'(다시 내릴 수 있음), [x] 는 '해낸 일'(다음 단계)로 읽음.

2) 진행 중 — 코딩/Claude 대화/YYYY-MM-DD-claude.md
   - "## 다음 할 일" 아래 "- [ ]" 줄을 그 자리에서 "- [x]" 로 바꿈.
   - "## 막혔던 점과 해결 방법", "## 다음 할 일" 제목과 파일 이름의 날짜는 바꾸지 않음.
   - 상소는 최근 7일 노트의 체크 안 된 것을 '진행 중'으로 읽음.

3) 오늘 기분 · 1년 뒤 나에게 — 어제보다 나은 오늘/
   - 오늘 기분: "## YYYY-MM-DD" 아래에 한두 줄 덧붙이기 (아래로 쌓기).
   - 1년 뒤 나에게: 파일 이름에 "1년 뒤" 포함 (예: 1년 뒤 나에게.md).

4) 보안
   - 깃허브 토큰(Fine-grained, my-wiki · Contents 읽기/쓰기)은 서버 쪽에서만 사용.
   - 웹앱 군령 화면은 로그인한 나만 볼 수 있게.
